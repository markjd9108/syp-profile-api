Archetype sample library

Twelve reference profiles, one per archetype, live on app.theperformancelens.com

Every link below opens a real hosted participant profile, generated by the live pipeline rather than mocked up. Show one on a phone or tablet and it behaves exactly as a participant's own profile does, because it is the same page.

The participants are invented and the employer is Sample Company Ltd. Every score set is checked against the live scoring rules, so each profile is one the router would genuinely produce for that archetype rather than a plausible-looking number.

The two workshops mirror each other. The Summit and The Keystone are the same archetype in each family, awarded when all three dimensions reach Strong, and each family then has three single-dimension leaders, one two-strong-one-thin profile, and a broad fallback.

The links are stable. Regenerating a sample reuses its profile ID and therefore its URL, so anything you print, bookmark or put behind a QR code keeps working.
